输入区

聊天输入框这一块。四个位置：composer.left（工具栏左侧）、composer.middle（工具栏右侧、模型选择左边）、composer.trigger（打触发符弹出的列表）、composer.content（输入框里的记号）。外加两组方法：读写草稿、读写附件。

长什么样：7 个场景，从默认样式到知识库选择、# 触发远程数据、插件实现增强、常用语、附件读写、草稿统计。

不写说明文字，只有界面

一句话回顾

  • 固定件不许动：左边是附件、模式切换、权限切换；模型选择和发送永远在最右。
  • 中槽的宿主默认项只有上下文用量；插件可以隐藏它、替换成自己的。
  • 宿主不再自带「提示词增强」，这个能力交给插件（demo 场景 4）。
  • 触发符注册制：插件声明一个符号，弹出列表的样式是宿主的，列表内容是插件的。
  • 选中的东西在输入框里是一个记号（chip），发送时按结构化数据解析。
  • 分支上旧的 beforeSend 整块移交原型（模型 + 上下文 + 增强整体交给一个插件）已废弃，按新边界重做。

还没定的事

中槽多个插件的排序、触发符与 / @ 的优先关系、记号的数据格式、附件方法的权限名——见 requirements.html 的「还没定的事」。
